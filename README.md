# Project description

## A music player that allows users to:

- Browse library songs.
- Play song, play previous song, next song.
- Add a song to favorite list.
- Remove a song from favorite list.

## Project stack:

- React
- React router
- Airtable for fetching song from aitable database
- Context API
- phosphor-react icons (npm package) for icons.

## Features:

- play a song
- Favorite playlist
- Main song library
- random song on inital state

## set up

- npm install
- npm run dev
